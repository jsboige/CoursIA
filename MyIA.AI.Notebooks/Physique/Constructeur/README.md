# Constructeur — les lois comme tâches possibles / impossibles

Sous-série conceptuelle de la série Physique. Là où `Jauge/`, `Numerique/` et
`Integrales/` font **calculer** contre une référence exacte, `Constructeur/` pose le
changement de point de vue qui sous-tend une partie de ces calculs : la théorie du
constructeur (Deutsch 2013 ; Deutsch & Marletto 2015), qui énonce les lois fondamentales
comme des énoncés sur les transformations **possibles** et **impossibles**, plutôt que
comme des équations de mouvement.

Les carnets sont en **Python 3**, sans GPU : le code illustre les notions (tâche,
constructeur, possible/impossible, support d'information) sur des systèmes jouets.

## Carnets

- **Constructeur-01 — Les lois comme tâches** — le vocabulaire (tâche, substrat, état,
  attribut, constructeur, possible/impossible), l'inversion dynamique → principes, la
  conservation comme tâche impossible, l'information comme support et le no-cloning, et
  le pont vers `Jauge/` (Noether), la localité (causal bridges) et l'hybridation
  quantique (gravité).
