# CopilotSDK — le SDK GitHub Copilot piloté depuis C#

Un seul carnet, un projet compagnon : le dossier existe parce que le carnet
[01-GitHub-Copilot-SDK-Binding.ipynb](01-GitHub-Copilot-SDK-Binding.ipynb) exécute le projet
.NET réel `CopilotAgent.App/` (un agent en streaming avec des endpoints typés) qui vit à côté
de lui. C'est cette raison de niveau — le projet qu'il exécute — qui justifie le dossier.

Axe **Copilot SDK** de la série *The Unexpected AI Stack: C#/.NET*
([EPIC #10473](https://github.com/jsboige/CoursIA/issues/10473)).
