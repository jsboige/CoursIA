# Scrutor — des endpoints de minimal API découverts par convention

Un seul carnet, un projet compagnon : le dossier existe parce que le carnet
[01-Scrutor-Endpoints-Par-Convention.ipynb](01-Scrutor-Endpoints-Par-Convention.ipynb)
exécute le projet .NET réel `ScrutorLab/` (un minimal API dont les endpoints sont découverts
par `Scan()`/`Registry`) qui vit à côté de lui. C'est cette raison de niveau — le projet qu'il
exécute — qui justifie le dossier.

Axe **Scrutor** de la série *The Unexpected AI Stack: C#/.NET*
([EPIC #10473](https://github.com/jsboige/CoursIA/issues/10473)).
