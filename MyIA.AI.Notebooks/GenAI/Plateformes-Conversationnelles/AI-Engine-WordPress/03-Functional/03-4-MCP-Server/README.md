# MCP server

[← README AI-Engine-WordPress](../../README.md

AI-Engine transforme WordPress en **serveur MCP** : des outils permission-aware (post, comment, media, theme, plugin, WooCommerce, Polylang, requêtes SQL, SEO) exposés à des agents comme Claude, Claude Code, ChatGPT et OpenClaw. OAuth supporté pour les clients desktop. AI-Engine peut aussi **consommer** des serveurs MCP externes.
