# Bibliographie partagée — archivage canonique hors Git

S'applique à tout agent qui récupère, utilise ou cite une publication externe.

## Règle HARD

Toute publication récupérée, utilisée ou citée est archivée dans le gisement partagé :

`G:\Mon Drive\MyIA\IA\Bibliographie IA`

Avant dépôt, rechercher par auteur **et** titre, vérifier l'identité sur la première page, puis ranger une seule copie dans le domaine principal. Une issue, une PR ou un dispatch cite le chemin GDrive complet.

**Lire avant d'attribuer.** Ce qu'un notebook, une issue ou une PR attribue à une publication (résultats, mesures, vocabulaire) s'écrit depuis la copie archivée, jamais depuis un résumé, une page d'accueil ou la mémoire du modèle. Publication inaccessible (mur anti-robot, paywall) : ne pas rédiger ce qui en dépend, inscrire une demande de dépôt au registre des questions user ([user-blocker-signaling.md](user-blocker-signaling.md)), prendre un autre grain. Une copie archivée **après** l'écriture oblige à relire contre elle ce qui a été écrit avant.

Les PDF et autres publications sous droits ne sont **jamais** committés dans CoursIA. Un dataset n'est pas assimilé à une publication : ne pas le recopier tant que sa provenance, sa licence, ses conditions d'utilisation et ses droits de redistribution ne sont pas établis.

Procédure, nomenclature et rayons : [bibliography-hygiene.md](../../docs/reference/bibliography-hygiene.md).
